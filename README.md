## Catbnb

Recreation of Airbnb website with attention to detail and features on said website (at least at the time of making it, since then it has changed quite a bit).

Created using vanilla JavaScript (no not even built in JQuery, also vanilla JS > React/Angular (yes i used both of those they are bad)), HTML and CSS with ASP.NET.

Database technologies are MSSQL with Entity Framework.

## Motivation behind this project
I was (after years i still am) annoyed how on youtube there are so much "tutorials" that are supposed to "teach" you programming, where in reality they just teach you copying code from videos and copying someone else way of programming without understanding anything (tutorial hell). So i created this project out of spite to create something better than 100% of these low effort tutorials and learn my own style and way of programming and solving problems. This website also has some things improved (in my personal opinion) since i disliked them in original Airbnb website.
